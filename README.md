## Featured Projects

### [spring-ai-rag](https://github.com/annusshah1998/spring-ai-rag) — RAG in Java

A retrieval-augmented generation service built natively in Java and Spring Boot — one of very
few RAG implementations in that ecosystem.

`PDF ingestion → Chunking (800 tokens) → pgvector embeddings → GPT-4o answers`

| | |
|:--|:--|
| **Stack** | Java 21 · Spring Boot 4 · Spring AI · OpenAI · pgvector · Docker |
| **Key features** | Metadata enrichment · Source citation · Cosine-similarity retrieval |
| **Why it matters** | Most RAG material targets Python; this fills the gap for Java teams |

### [Taqaza](https://annusshah1998.github.io/taqaza-site/) — invoice & payment tracker for Android and iPhone

*Taqaza* (Urdu for "a demand for payment") is an offline-first mobile app built for a printing
business. Clients pay in lump sums; the app splits each payment across open invoices — oldest
first or by hand — and keeps every invoice and client balance current, with all data kept on
the phone.

| | |
|:--|:--|
| **Stack** | React Native · Expo · TypeScript · SQLite |
| **Key features** | Automatic payment allocation · Credit notes & write-offs · Client statements & aging · PDF invoices and statements · Daily on-device backups & restore · Face ID / passcode lock |
| **Engineering** | Money stored as whole rupees; balances always derived from payments, allocations and credit notes, never stored; all ledger rules pure and unit-tested |
